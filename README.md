V12 follows the corrected FRONT / BACK route in `opus-brand-pack/V12_INDEPENDENT_REVIEW.md`. The explicit `settings.bts_review_fallback` checkbox enables generated theme-local review scalars when content/config entries are unavailable. It defaults false and is enabled only in the unpublished review configuration deployed here. Run `node scripts/build-review-fallback.mjs` after approved seed changes, or `--check` to verify parity. Draft-safe Add controls remain disabled without a purchasable Shopify variant; checkout remains locked. Definitions/entries/preview Pages have not been created in Admin.
